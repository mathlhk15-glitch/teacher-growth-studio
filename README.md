# 교사 수업·평가·기록 설계실

학생 성장 플랫폼 v10의 교사용 별도 도구입니다. 학생용 저장소와 URL을 분리해 배포하는 것을 권장합니다.

## 구성

- `index.html`: 교사용 허브(처음 순서 안내, 1분 요약 포스터, 용어 대응표)
- `guide.html`: 진짜 탐구 수행평가 기본형 가이드 v2.1
- `framework.html`: 심화형 개념기반 탐구 수행평가 프레임워크
- `assets/`: 교사용 핵심 요약 포스터, 실천 가이드 PDF, 학생용 포스터 PART 1·2
- `assessment.html`: 수행평가 설계 및 외부 AI용 프롬프트 생성
- `record-check.html`: 세특 사전 진단, 프롬프트 생성, UTF-8 바이트·금지 표현·중복 표현 검수
- `teacher-standards.js`: 공통 교육 기준과 진단 규칙
- `assessment.js`, `record-check.js`, `common.js`: 기능 로직
- `styles.css`: 공통 디자인
- `CLAUDE_PROJECT_INSTRUCTIONS.md`: 개인용 Claude Project 권장 지침

## 핵심 설계

### 수행평가

- 성취기준은 교사가 직접 붙여넣음
- 학생 선택권, 과정 관찰, 중간 피드백, 수정 증거를 구조화
- 0~4 성장단계는 점수표가 아니라 과정 피드백 보조척도로 활용
- API 호출 없이 프롬프트를 생성해 원하는 AI에 붙여넣음
- 수행평가 설계 내용은 사용자가 선택할 때만 JSON 파일로 저장

### 세특

- 빈칸에서 세특을 생성하지 않음
- 교사 초안 또는 실제 관찰 메모가 필요
- 입력 내용은 localStorage에 저장하지 않음
- 문장 생성은 외부 AI가 담당
- HTML은 근거 진단, 정확한 UTF-8 바이트 계산, 금지·추정 표현 검사, 원문 대비 추가 단어 후보, 여러 학생 표현 중복 탐색을 담당

## 배포

정적 GitHub Pages에서 동작합니다. 별도 빌드나 서버가 필요하지 않습니다.

1. 파일 전체를 별도 GitHub 저장소 루트에 업로드합니다.
2. GitHub Pages를 활성화합니다.
3. 학생용 프로그램에서는 직접 링크하지 않는 것을 권장합니다.
4. 세특 원문을 다루므로 교사용 URL로만 안내합니다.

## 개인정보

`record-check.html`은 localStorage를 사용하지 않습니다. 다만 웹브라우저 화면과 클립보드에는 입력 내용이 존재하므로 공동 PC에서는 사용 후 `전체 지우기`를 누르고 창을 닫으세요. 외부 AI 사용 전 식별정보를 반드시 제거하세요.

## 한계

- 규칙 기반 근거 진단과 추가 단어 검사는 의미를 완전히 이해하는 AI 검사가 아닙니다.
- 추가 단어 후보에는 정상적인 문장 연결어와 활용어도 포함될 수 있습니다.
- 학교 학생부 기재 지침, 평가계획, 개인정보 및 AI 활용 지침을 대체하지 않습니다.
